Row has no `position` (in flow, covers nothing). `min-width: 0` present on body/list-btn/species/span. Mirrors `.map-canvas__legend` declarations.

- Tests: no jest-dom; exact `toEqual` on names/srcs; wiring W1/W2/W5/W7/W8, L1, L2, L3, C1 each have a red test (by reading). Test names honest.
- 730 lazy icons: `loading="lazy"` + `width/height` attrs inside a 40vh scroll container, so only visible rows fetch, no layout shift. `alt=""` correct (name is adjacent text).
